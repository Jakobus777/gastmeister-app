GitHub-Sync

Synchronisiert Buchungsdaten zwischen allen Geräten (Mac, iPhone) über GitHub. Änderungen werden automatisch hochgeladen.

Token erstellen: GitHub → Settings → Developer Settings → Fine-grained tokens → Repo: gastmeister, Contents: Read+Write

Hinweis zur Datensicherung

Es wird empfohlen, regelmäßig (z.B. wöchentlich) ein Backup zu erstellen und die Datei an einem sicheren Ort aufzubewahren. Das JSON-Format eignet sich für die technische Wiederherstellung, das Excel-Format für die Archivierung und Einsichtnahme.
